For the friend helping Aniket. About 2 hours. Ticks are saved in this browser.

Work with the Excel sheet Bhoomija_Variant_Images_Checklist.xlsx open. Tick a product here when it is done, and write any problem in the sheet. Do not change titles, descriptions or prices. Only link images, and report everything else.

How to link a variant image (about 1 minute per variant)

  1. Open the product link below. The Shopify admin opens.
  2. Scroll to Variants and click one variant, for example "Mustard".
  3. Click the image square next to the variant name, pick the matching photo from the product media, then click Done and Save.
  4. Repeat for each variant. If no photo matches a colour, write "no photo" in the sheet. Don't guess.
  5. Open the product on the live store (the eye icon, "View"). Click each colour and check that the main image changes.
